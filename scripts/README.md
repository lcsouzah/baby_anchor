# Baby Anchor Simulation Runner

The simulation runner has been upgraded into the **ACBA Simulation Lab**.

Primary entrypoint remains:

```bash
yarn simulate
```

Implementation lives in `scripts/simulation/`:
- `runner.ts`
- `agents.ts`
- `scenarios.ts`
- `analytics.ts`
- `outputs.ts`
- `types.ts`
- `config.ts`

See `SIMULATION.md` for full usage, scenarios, analytics definitions, and output schema.
